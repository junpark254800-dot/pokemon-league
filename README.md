# 포켓몬 리그 — 공개 테스트 사이트

사이트 주소: https://junpark254800-dot.github.io/pokemon-league/

## 링크 바꾸는 법
1. 이 저장소에서 **`config.js`** 파일을 눌러 열어요.
2. 오른쪽 위 연필(✏️) 버튼을 눌러요.
3. 따옴표(" ") 안의 주소만 바꿔요. (다운로드 링크, 서버 주소, 디스코드, 포스터, 추가 링크)
4. 오른쪽 위 **Commit changes** → 다시 **Commit changes**.
5. 1~2분 뒤 사이트에 반영돼요. (안 바뀌면 새로고침: Ctrl+F5)

## 파일
- `index.html` — 사이트 본문
- `config.js` — 링크·서버 주소 설정 (여기만 고치면 됨)
- `img/v12/` — v12 사이트 사진 (게임 안 스크린샷) · `og.jpg` 는 디스코드 미리보기 이미지
- `tracks.js` · `audio/` — 사운드트랙 목록과 곡 파일
- `trailer.mp4` · `cover.jpg` — 지난 시즌(v11) 트레일러 (사이트 맨 아래)
